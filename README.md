# TaskProof

TaskProof — локальный CLI для одного проверяемого цикла инженерной задачи: контракт, baseline, фиксированная проверка, review и закрытие. Сейчас поддержан один preset: проверка пробелов в staged diff через Git. TaskProof не доказывает качество изменений, авторство или независимость review.

Начало работы, точная схема JSON и полный синтетический пример: [руководство CLI](docs/CLI.md). Команды запускаются из корня проекта через `python3 -m taskproof`; отдельная установка пакета не нужна.

Для каждой задачи укажите абсолютный путь к хранилищу вне проверяемого репозитория. Контракт, review JSON и хранилище тоже должны находиться вне него. В репозитории нужен исходный Git commit: проверка сравнивает staged diff с `HEAD`.

Текущий CLI — ограниченный локальный срез. Он использует строгую схему и локальные HMAC-подписанные записи для обнаружения изменения журнала; ключ находится рядом в локальном хранилище. Это не защита от владельца машины, подмены программы или ключа, не внешнее подтверждение личности и не изоляция хоста. Сырой вывод Git отбрасывается; журнал сохраняет только счётчики, код завершения, timeout/truncation и длительность. Runner задаёт лимит времени и вывода и POSIX resource limits; лимит памяти задан только на Linux. Эта проверка не подтверждает универсальную безопасность исполнения.

`Review` в контракте требует квитанцию оператора для того же снимка. Сам JSON не доказывает, кто выполнил review. Если запрошена обязательная независимость, текущий CLI закрывается fail-closed: без доверенного адаптера такой review не подтверждается. `TDD-first`, произвольные команды, дополнительные критерии и произвольные действия контрактом не поддерживаются.

Синтетическая первая фикстура в [tests/test_template_fixture.py](tests/test_template_fixture.py) создаёт одноразовый Git-репозиторий с нейтральными файлами, проводит реальную проверку staged whitespace и проверяет блокировку до исправления. Это проверка формы первого подключения; она не сертифицирует интеграцию с `web-app-template`.

## Статус

Реализованы локальный цикл CLI и один Git preset. Этот репозиторий содержит также синтетические проверки и документацию. Навыки продукта, installer, CI и адаптеры к хостам или агентам не входят в этот срез. Локальные тесты не означают commit, публикацию, CI, deployment или работу в production.
