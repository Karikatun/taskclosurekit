# TaskProof

Локальный CLI и набор навыков для проверяемого выполнения инженерных задач. TaskProof должен связывать договорённость о задаче, состояние проекта и доказательства выполнения, чтобы агент не объявлял работу законченной по неполному или устаревшему отчёту.

Сейчас здесь только стартовые документы. CLI, навыки продукта, тесты и установщик ещё не реализованы. GitHub remote и публикация проверяются отдельно и не следуют из наличия этой папки.
